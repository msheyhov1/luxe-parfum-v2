# LUXE Парфюмерный дом

Публичная статическая витрина нишевой и элитной парфюмерии.

## Возможности

- бело-чёрная редакционная дизайн-система;
- пятислайдовая hero-карусель;
- популярные бренды и промо-блоки;
- категории «Для него», «Для неё», «Унисекс», «Туалетная вода»,
  «Масляные духи» и «Ароматы для дома»;
- фильтры новинок, бестселлеров и скидок;
- карточки товаров, избранное, корзина и оформление заказа;
- журнал о парфюмерии с четырьмя редактируемыми материалами;
- адаптивная мобильная версия.

## Запуск

Проект не требует сборки:

```bash
python3 -m http.server 8000
```

После запуска откройте `http://localhost:8000`.

## Редактор журнала

Ссылка на редактор: `/#journal-admin`.

Доступ закрыт отдельным логином и паролем. В репозитории сохранены только их
SHA-256-хэши. Данные входа передаются владельцу отдельно и не публикуются здесь.

Изменения материалов сохраняются в `localStorage` текущего браузера. Это
ограничение статического GitHub Pages: для общей серверной админ-панели и
синхронизации изменений между пользователями потребуется backend и база данных.

## Хранение данных

Корзина, избранное, демонстрационные аккаунты, сессия покупателя и материалы
журнала хранятся локально в браузере. Проект является front-end демонстрацией и
не должен использоваться как настоящая система аутентификации или оформления
заказов без серверной части.
